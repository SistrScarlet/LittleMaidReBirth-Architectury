# Ready Commit Command

## Description
変更を確認して、docs/temp.mdにコミットコメントを書く。
コミットはユーザーが手動で行う。

## Usage
```
/ready_commit
```

## Implementation

```bash
# 変更内容を確認
git status
git diff --cached
git diff

# コミットコメントをdocs/temp.mdに作成
# コミットメッセージ形式ガイドに従って自動生成

echo "変更内容を確認し、docs/temp.mdにコミットコメントを作成しました。"
echo "コミットはユーザーが手動で行ってください。"
```

## コミットメッセージ形式ガイド

このプロジェクトでは以下の形式でコミットメッセージを書いてください。

### 基本ルール

1. **日本語で機能や変更内容を簡潔に記述**
2. **バージョン番号のみの場合はリリースコミット**
3. **具体的な修正内容を分かりやすく説明**

### 良い例

- `ターゲティングシステムの基盤とプロジェクトドキュメントを追加`
- `雇用メイドさんに野良テクスチャを当てた時、再読み込みで見た目が雇用状態になるのを修正`
- `モード続行不可時にリセット処理をしていなかったのを修正`
- `最大ターゲット距離追加`

### 注意点

- 何を修正・追加したかを明確に
- メイドさんに関する修正では「メイドさん」という表現を使用
- 技術的な詳細よりもユーザーが理解しやすい表現を優先

## Notes
- Pythonキャッシュファイルなどの不要なファイルが含まれている場合は.gitignoreの修正も提案
- 既存のdocs/temp.mdは上書きされます
- コミット実行は手動で行う必要があります
