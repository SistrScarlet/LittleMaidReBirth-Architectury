# Little Maid Rebirth (LMRB) - プロジェクト概要と総合評価

## 📋 プロジェクト概要

Little Maid Rebirth (LMRB) は、Minecraft用の高度なAI機能を持つメイドさんMODです。単なるペットやNPCを超えた、プレイヤーの真のパートナーとして機能する知的なエンティティシステムを実装しています。

### 基本情報
- **プロジェクト名**: Little Maid Rebirth (LMRB)
- **対象バージョン**: Minecraft 1.20.1
- **フレームワーク**: Architectury API (Fabric/Forge両対応)
- **プログラミング言語**: Java
- **ライセンス**: [要確認]

## 🏗️ アーキテクチャ概要

### パッケージ構成
```
net.sistr.littlemaidrebirth/
├── entity/         (61ファイル) - メイドさんエンティティの核心システム
├── goal/           (22ファイル) - AI行動ゴールシステム  
├── mode/           (13ファイル) - 戦闘・作業モードシステム
├── mixin/          (14ファイル) - Minecraftコードとの統合
├── network/        (9ファイル)  - クライアント・サーバー間通信
├── util/           (8ファイル)  - ユーティリティクラス群
├── api/            (7ファイル)  - 外部API定義
├── client/         (7ファイル)  - クライアント側レンダリング
├── iff/            (6ファイル)  - 敵味方識別システム
└── その他          (20ファイル) - 設定、セットアップ、ワールドデータ等
```
**総計**: 118個のJavaファイル

### 設計思想

#### 1. **モジュラー設計**
各システムが独立性を保ちながら連携する構造：
- **Goal**: AI行動の基本単位
- **Mode**: 専門的な作業・戦闘モード
- **Targeting**: 統合的な敵対判定システム
- **IFF**: 敵味方識別システム

#### 2. **委譲パターンの活用**
LittleMaidEntityは複数のインターフェースを実装し、各機能を専用クラスに委譲：
```java
public class LittleMaidEntity extends TameableEntity implements
    HasInventory, Contractable, HasMode, HasIFF, AimingPoseable, ...
```

#### 3. **階層化された優先度管理**
明確な優先順位による行動制御：
1. **緊急行動**: 生存に関わる行動（水泳、緊急テレポート）
2. **生存行動**: 体力管理、給料収集、待機
3. **戦闘行動**: 危険回避、戦闘、追従
4. **日常行動**: アイテム管理、娯楽、探索

## 🤖 主要システム概要

### AI行動システム
- **16個の主要Goal**による階層的行動管理
- **競合回避**: conflictsWith()による同時実行制御
- **動的制御**: canStart()とshouldContinue()による実行制御

### ターゲティングシステム
**7段階の優先度計算**による高度な戦闘判断：
1. **基本優先度**: 脅威レベルによる階層化
2. **距離修正**: メイドさんとご主人両方からの距離を考慮
3. **武器相性**: 弓は遠距離有利、剣は近距離有利
4. **危険修正**: 特別な危険敵への回避判定
5. **分散攻撃**: 複数メイドさんでの協調戦闘
6. **マスタースタンス**: 護衛モード・援護モードの切り替え
7. **負傷者保護**: 負傷した仲間の攻撃者への優先対処

### 敵味方識別（IFF）システム
- **3段階判定**: FRIEND、ENEMY、UNKNOWN
- **自動判定**: エンティティタイプによる基本設定
- **手動設定**: プレイヤーによる個別カスタマイズ

## ⚙️ 技術的特徴

### 使用技術スタック
- **Architectury API**: クロスプラットフォーム（Fabric/Forge）対応
- **AutoConfig**: TOML形式での設定管理
- **Mixin**: Minecraftコアの非侵襲的拡張
- **DeferredRegister**: 遅延登録による安全なリソース管理
- **DataTracker**: エンティティ状態の同期
- **PersistentState**: ワールドデータの永続化

### パフォーマンス対策
- **ProcessDivider**: 重い処理の分散実行
- **キャッシュシステム**: 計算結果の効率的な再利用
- **非同期処理**: ブロック探索等の負荷分散
