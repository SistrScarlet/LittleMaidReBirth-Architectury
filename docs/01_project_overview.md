# Little Maid Rebirth (LMRB) - プロジェクト概要と総合評価

## 📋 プロジェクト概要

Little Maid Rebirth (LMRB) は、Minecraft用の高度なAI機能を持つメイドさんMODです。単なるペットやNPCを超えた、プレイヤーの真のパートナーとして機能する知的なエンティティシステムを実装しています。

### 基本情報
- **プロジェクト名**: Little Maid Rebirth (LMRB)
- **対象バージョン**: Minecraft 1.20.1
- **フレームワーク**: Architectury API (Fabric/Forge両対応)
- **プログラミング言語**: Java
- **ライセンス**: [要確認]

## 🏗️ アーキテクチャ概要

### パッケージ構成
```

├── client/         (7ファイル)  - クライアント側レンダリング
└── その他          (20ファイル) - 設定、セットアップ、ワールドデータ等
```
**総計**: 118個のJavaファイル

### 設計思想

#### 1. **モジュラー設計**
各システムが独立性を保ちながら連携する構造：
- **Goal**: AI行動の基本単位
- **Mode**: 専門的な作業・戦闘モード
- **Targeting**: 3段階優先度計算による戦闘判定システム
- **TargetTag**: エンティティ別の細かい制御システム

#### 2. **委譲パターンの活用**
LittleMaidEntityは複数のインターフェースを実装し、各機能を専用クラスに委譲：
```java
public class LittleMaidEntity extends TameableEntity implements
    HasInventory, Contractable, HasMode, TargetTagManager, AimingPoseable, ...
```

#### 3. **階層化された優先度管理**
明確な優先順位による行動制御：
1. **緊急行動**: 生存に関わる行動（水泳、緊急テレポート）
2. **生存行動**: 体力管理、給料収集、待機
3. **戦闘行動**: 危険回避、戦闘、追従
4. **日常行動**: アイテム管理、娯楽、探索

## 🤖 主要システム概要

### AI行動システム
- **16個の主要Goal**による階層的行動管理
- **競合回避**: conflictsWith()による同時実行制御
- **動的制御**: canStart()とshouldContinue()による実行制御

### ターゲティングシステム
**3段階の優先度計算**による効率的な戦闘判断：
1. **CRITICAL**: 自分の身を守る（メイドさん自身への脅威）
2. **HIGH**: ご主人の身を守る（プレイヤーへの脅威）
3. **NORMAL**: 味方の身を守る・周囲の対象（その他のターゲット）

**TargetTagシステム**による細かい制御：
- **接近禁止**: Creeperなど爆発系エンティティへの安全距離維持
- **攻撃禁止**: Wither、Ender Dragonなど危険エンティティの回避
- **先制攻撃禁止**: 友好的エンティティへの反撃のみ許可
- **武器制限**: 近接/遠距離武器の使い分け制御

### TargetTagシステム（敵味方識別）
- **5種類のTargetTag**: 接近禁止、攻撃禁止、先制攻撃禁止、近接攻撃禁止、遠距離攻撃禁止
- **エンティティ別設定**: プレイヤーが各エンティティに個別にタグを設定可能
- **フィルタリングUI**: TargetTagScreenで検索・設定が直感的に操作可能
- **リアルタイム同期**: 設定変更が即座にサーバーに反映

## ⚙️ 技術的特徴

### 使用技術スタック
- **Architectury API**: クロスプラットフォーム（Fabric/Forge）対応
- **AutoConfig**: TOML形式での設定管理
- **Mixin**: Minecraftコアの非侵襲的拡張
- **DeferredRegister**: 遅延登録による安全なリソース管理
- **DataTracker**: エンティティ状態の同期
- **PersistentState**: ワールドデータの永続化

### パフォーマンス対策
- **ProcessDivider**: 重い処理の分散実行
- **キャッシュシステム**: 計算結果の効率的な再利用
- **非同期処理**: ブロック探索等の負荷分散
