## 実装されたアルゴリズムの特徴

### 1. 優先度階層システム
```
特別優先度: 危険敵からの避難・防御的対応 (-1000)
優先度1: 攻撃してきた相手 (1000)
優先度2: ご主人を攻撃した相手 (900)
優先度3: 他メイドさんを攻撃した相手 (800)
優先度4: ご主人が攻撃した相手 (700)
優先度5: 負傷メイドさんの支援・カバー (600)
優先度6: 周囲のEnemy (500 or 0)
```

### 2. 修正値システム
- **距離修正**: 近距離ボーナス、最大距離制限
- **武器相性修正**: 弓vs遠距離優位、エンダーマン完全回避
- **危険敵修正**: ウィザー等への慎重アプローチ
- **分散攻撃修正**: 集中ターゲットのペナルティ

## 実測値例

### 典型的な優先度スコア
- **ご主人攻撃者**: 900点台（最優先）
- **通常敵**: 500点台（基本）
- **エンダーマン（弓）**: 0点（完全回避）
- **危険敵（待機）**: 0点（先制攻撃回避）
- **危険敵（ターゲット）**: 負の値（避難）

### 武器特性の効果
- **弓の遠距離ボーナス**: +30点
- **剣の近距離ボーナス**: +20点
- **エンダーマン回避**: -1000点（弓のみ）

### 分散攻撃の効果
- **集中ペナルティ**: -50点/メイドさん
- **例**: 2体集中時 565→465点（100点減）

## 検証された設計原則

1. **生存優先**: 危険敵には慎重に対応
2. **攻撃者優先**: 攻撃してきた敵を最優先
3. **武器特性活用**: 弓は遠距離、剣は近距離に適性
4. **チーム連携**: 分散攻撃と相互支援
5. **距離考慮**: 近い敵ほど高優先度

## Java実装への変換時の注意点

1. **数値パラメータ**: 現在の値は調整可能
2. **パフォーマンス**: 大量のメイドさんでの最適化必要
3. **イベント連携**: 攻撃/被攻撃イベントとの統合
4. **設定外部化**: ゲームバランス調整のための設定分離
